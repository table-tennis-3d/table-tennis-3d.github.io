# フォーム3D

スポーツのフォームを自撮りした動画から、AIが全身の関節の位置を推定して **3Dモデルで再生** するWebアプリです。
卓球・テニス・ゴルフ・野球などのスイングや素振りを、好きな角度から・スローで・何度でも確認できます。

- インストール不要。ブラウザで開くだけで動きます（スマホ対応、ホーム画面に追加可）
- **動画は端末の中だけで処理** され、サーバーには送信されません
- ビルド不要の静的サイトなので、GitHub Pages にそのまま置けます

## できること

| 機能 | 内容 |
| --- | --- |
| 3Dモデル化 | 動画を1コマずつ解析し、体の33か所の3D位置からデッサン人形風の3Dモデルを動かします（骨格表示にも切り替え可） |
| 自由な視点 | ドラッグで回転、ピンチ/ホイールで拡大。「撮影視点・正面・右から・左から・背面・真上」はワンタップ |
| 再生 | 0.1〜1倍のスロー再生、コマ送り、ループ。元動画に骨格を重ねて同時に表示 |
| スイングごとのループ | 手首がいちばん速い瞬間（インパクト付近）を自動で見つけ、選んだスイングの前後だけを繰り返し再生 |
| 人物の指定と追従 | ほかの人が映っている動画でも、解析したい人を枠で囲んで指定できます。解析中は枠がその人を追いかけ、別の人に乗り移らないようにします |
| 数値・グラフ | 肘・膝・脇・股関節の角度、腰と肩の回転、捻転差、上体の傾き、手首の速さ、腰の高さ、スタンス幅、体の横移動 |
| 比較 | 履歴・別の動画・保存データを半透明の人形で重ね、山場で自動的にタイミングを合わせます。左右反転も可 |
| 履歴 | 解析結果（と元の動画）を端末のブラウザの中に自動保存。再解析なしで開けます |
| 保存・共有 | 3D画面の画像（PNG）、3Dアニメーションの動画（MP4/WebM）、解析データ（JSON）。スマホでは共有シートから保存できます |
| オフライン | 一度使ったあとは、電波の届かない場所でも開いて解析できます |

## 使い方

1. **撮る** — カメラを三脚などで固定し、全身が映るように撮影します。
2. **選ぶ** — 「動画を選ぶ」から動画を選び、解析する範囲（スイングの少し前〜少し後ろ）を決めます。
3. **作る** — 「3Dモデルを作る」を押すと解析が始まります。10秒の動画で数十秒〜1分ほどです（端末によります）。
4. **見る** — 3D画面を回したり、グラフをタップしてその瞬間に移動したりして確認します。

詳しい使い方と撮り方は、サイト内の「使い方と撮り方」（`guide.html`）にまとめています。

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にして、公開したいブランチと `/ (root)` を選んで **Save**
3. 数分後に `https://<ユーザー名または組織名>.github.io/<リポジトリ名>/` で開けます

リポジトリ名を `<ユーザー名または組織名>.github.io` にすると、`https://<名前>.github.io/` の直下で公開されます。

### 広告（Google AdSense）を貼る場合

- `ads.txt` はサイトのルート（`https://<ドメイン>/ads.txt`）に置く必要があります。そのため、リポジトリ名を `<名前>.github.io` にしてルート直下で公開するか、独自ドメインを設定してください。
- 審査の前に、プライバシーポリシー（`privacy.html`）へ広告配信と Cookie についての記載を追加してください。
- `sw.js` は、このサイト自身のファイルと、バージョン固定のライブラリ・AIモデル以外の通信にはさわらないので、広告の配信と干渉しません。

### 手元で試す

ES Modules を使っているため、`index.html` をダブルクリックで開くと動きません。簡単なHTTPサーバーで開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 仕組み

1. **コマ数の検出** — 動画を少しだけスロー再生して実際のコマ数（1秒あたり）とコマの切れ目を調べ、各コマの真ん中の時刻を1枚ずつ取り出します。同じコマを2回解析したり、コマを飛ばしたりしません。
2. **姿勢推定** — [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（`@mediapipe/tasks-vision` 0.10.21）で、腰の中心を原点としたメートル単位の3D座標（world landmarks）を推定します。GPUが使えない端末では自動的にCPU処理に切り替えます。人物を枠で囲んだ場合は、その中から人物を探し、見つけたあとは人物を中心にした窓を切り抜いて推定します（窓は人物の位置と大きさに合わせて動きます）。体の大きさや位置が急に変わった推定結果は別人とみなして捨て、その場所を一時的に隠して探し直します。
3. **後処理**
   - 検出できなかったコマは前後から補間します。
   - 平滑化は、見え具合（visibility）で重み付けした局所2次回帰です。関節ごと・コマごとに幅を変え、止まっているときは広く、速く動いているときはほとんど平均しないので、スイングの山を削りません（位相のずれもありません）。速度も同じ当てはめから求めます。
   - 奥行き（カメラからの前後）は1台のカメラでは不安定で、1コマで大きく飛ぶことがあるため、奥行きだけ幅を広げています。
   - 足が床に着くように高さを補正し、画像上の位置から体の横移動（カメラから見て左右）を復元します。
4. **3D表示** — [three.js](https://threejs.org/)（0.170.0）で、関節の位置から人形の各パーツ（楕円体とテーパー付きの円柱）の位置と向きを毎フレーム計算して描きます。
5. **分析** — 3D座標から関節角度・回転角・速度を計算します。腰と肩の回転は、クリップ全体の平均の向きを0°として、上から見て左回りを＋にしています。

ライブラリとAIモデルは CDN（jsDelivr / Google）から読み込み、サービスワーカー（`sw.js`）が端末にキャッシュします。外部のCDNに接続できない環境で使う場合は、ページの先頭で `window.FORM3D_ASSETS` を定義すると、同じサーバーに置いたファイルを使えます（書き方は `js/config.js` の先頭を参照）。

## 知っておいてほしい制限

- 1台のカメラの映像から3Dを **推定** しているため、カメラに対して前後（奥行き）方向の位置は誤差が大きめです。
- ラケット・バット・ボールは追跡しません。指先の細かい動きや手首の角度も大まかです。
- 体の移動は、カメラから見て左右の動きだけを再現します。前後（奥行き）の移動は再現しません。
- 1秒30コマの動画では、速いスイングのいちばん速い瞬間をとらえきれず、速さが低めに出ます。60コマ以上での撮影がおすすめです。
- 角度や速さは目安です。同じ場所・同じ角度で撮った動画どうしで比べると、変化が分かりやすくなります。
- 履歴はブラウザの中（IndexedDB）に保存します。ブラウザのデータを消すと一緒に消えます。
- 対応ブラウザ：最新の Chrome / Edge / Safari（iOS 16.4以降）/ Firefox。iPhone の「高効率（HEVC）」形式の動画は、パソコンの一部のブラウザでは再生できないことがあります。

## ファイル構成

```
index.html            アプリ本体の画面
guide.html            使い方と撮り方
metrics.html          数値の見方
faq.html              よくある質問
privacy.html          プライバシーポリシー
about.html            このサイトについて
manifest.webmanifest  ホーム画面に追加するための設定
sw.js                 オフライン対応（サービスワーカー）
icons/                アイコン
css/style.css         アプリの見た目
css/pages.css         説明ページの見た目
js/main.js            画面の制御（読み込み・解析・再生・設定・比較・履歴・保存）
js/pose-extractor.js  コマ数の検出と、MediaPipe による姿勢推定
js/motion.js          補間・平滑化・速度・床の補正・体の向きと横移動
js/analysis.js        角度・回転・速さ・山場の検出
js/viewer3d.js        three.js による3D表示（人形・骨格・軌跡・比較）
js/overlay2d.js       元動画への骨格の重ね描き、人物の範囲の枠
js/chart.js           グラフ
js/history.js         履歴（IndexedDB）
js/io.js              解析データ（JSON）の保存と読み込み
js/landmarks.js       33点の定義
js/config.js          ライブラリ・モデルの読み込み先
```
