プライバシーポリシー

フォーム3D（以下「当サイト」）での、利用者の情報の取り扱いについて説明します。

動画と解析結果の取り扱い

当サイトで選んだ動画は、お使いの端末のブラウザの中だけで解析します。動画、解析結果、3Dモデルを、当サイトのサーバーやその他の外部に送信することはありません。運営者が利用者の動画や解析結果を見ることもできません。

端末の中に保存するもの

当サイトは、使いやすくするために、次の情報をお使いの端末のブラウザの中に保存します。これらは端末の外に送信されません。

  • 設定 — 利き手、表示の設定、再生速度など。
  • 履歴 — 解析結果、一覧に出す小さな画像、利用者が付けた名前。「元の動画も履歴に残す」を選んでいる場合は、元の動画も保存します。
  • プログラムとAIモデルの控え — 2回目以降に素早く開けるように、また電波の届かない場所でも使えるように、当サイトのプログラムとAIモデルを保存します。

履歴は、トップ画面の「履歴」から1件ずつ、または「履歴をすべて消す」でまとめて削除できます。ブラウザの設定から当サイトのデータを消去すると、上記のすべてが削除されます。

外部のサービスへの接続

当サイトのページとプログラムを表示するために、お使いのブラウザは次のサービスに接続します。接続の際、一般的なウェブサイトの閲覧と同じように、IPアドレスやブラウザの種類などの情報が各サービスに送られます。動画や解析結果は送られません。

  • GitHub Pages（GitHub, Inc.） — 当サイトのページを配信しています。
  • jsDelivr — 3D表示と姿勢推定のプログラム（three.js、MediaPipe）を配信しています。
  • Google Cloud Storage（Google LLC） — 姿勢推定のAIモデルを配信しています。

これらのサービスでの情報の取り扱いは、各サービスのプライバシーポリシーに従います。

アクセス解析と広告

現在、当サイトはアクセス解析ツールと広告配信サービスを使用していません。Cookie を使って利用者を追跡することもありません。

今後、これらを導入する場合は、導入の前にこのページを更新し、使用するサービス、取得される情報、無効にする方法をお知らせします。

お子さまの利用について

当サイトは、個人を特定する情報を集めません。お子さまが利用する場合は、保護者の方と一緒にご利用ください。ほかの人が映っている動画を扱うときは、映っている方の了承を得てください。

このポリシーの変更

内容を変更する場合は、このページでお知らせします。大きな変更があるときは、トップ画面でも案内します。

お問い合わせ

このポリシーについてのお問い合わせは、このサイトについてに記載の連絡先までお願いします。
